La variante 8 Go (GA106, bus 128 bits, 240 Go/s) est dans `DEVICES` pour être refusée comme référence. Même nombre de shaders, mémoire et bus insuffisants : le test « cité + 1080p Performance » déborde sur 8 Go et tient sur 12.

## Ce qu'on n'emprunte pas à Ada

La 4060 est dans le catalogue pour que le plan le dise : SER, OMM et Frame Generation existent plus haut dans la gamme et **restent hors contrat**. Un shader de rayons écrit pour SER sera plus lent sur la 3060, pas plus joli. Le plan borne les rebonds à 1 plus les ombres.

## Resizable BAR

Ampere en profite vraiment. Avec ReBAR, l'anneau d'upload fait 64 Mo mappé et la file copie est à 0. Sans ReBAR, l'anneau passe à 256 Mo et une file copie réapparaît. Le conseil est dans `budgetMemory` : l'activer, ne pas le compenser avec plus de workers CPU. Le bus 192 bits sature avant un Ryzen 6 cœurs.

## Files

28 SM ne recouvrent pas deux compute async et un raster Series (mesh shaders + matières). `planQueues` impose :

- 1 file graphique
- 1 file compute async (build DXR, pas un second univers)
- 0 ou 1 file copie selon ReBAR
- 2 workers CPU d'upload

Au-delà de 30 SM (3070, 3080), le plan passe à 2 files async et 4 workers. Ce n'est pas le défaut.
